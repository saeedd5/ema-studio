# 🎙️ استودیوی ویدیویی اِما (Emma Video Studio)

موتور قدرتمند، سبک و تحت وب برای تولید و تدوین خودکار ویدیوهای عمودی (۱۰۸۰×۱۹۲۰) ریلز و استوری بر پایه مکالمات صوتی هوش مصنوعی و انسان.

## ✨ قابلیت‌های کلیدی
- ⚡ **رندر فوق‌سریع سخت‌افزاری:** تولید مستقیم فایل MP4 در مرورگر با شتاب سخت‌افزاری با استفاده از WebCodecs و Mp4Muxer.
- 🎛️ **موتور صوت پیشرفته:** تقویت ولوم تا ۳۰۰٪ به همراه DynamicsCompressor برای حفظ کیفیت و شفافیت صدا.
- ⏱️ **سیستم برش و چسباندن چند بازه (Multi-Range Stitcher):** انتخاب و اتصال میلی‌متری چند قطعه دلخواه از صدا بدون نیاز به نرم‌افزارهای سنگین تدوین.
- 🏷️ **نشانگرها و لیبل‌های متصل به صدا (Audio Callout Pins):** ایجاد پین‌های توضیحی با انیمیشن نئونی هوشمند، هاله نور و تنظیم ارتفاع اختصاصی (Y).
- 🪄 **تقطیع هوشمند گفتار (Adaptive VAD):** تشخیص اتوماتیک سکانس‌های مکالمه و تولید زمان‌بندی دقیق زیرنویس.
- 💾 **پایداری داده‌ها (Persistence):** ذخیره‌سازی داده‌های سنگین در IndexedDB و ذخیره پوشه محلی با File System Access API.
- 🎨 **معماری قالب‌های ماژولار (Plugin-based):** پشتیبانی از چندین تمپلیت بصری.
